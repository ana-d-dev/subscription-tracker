Technology stack

SubTrack is built using modern web technologies with a focus on clean architecture, maintainability, and security. Every technology was selected to demonstrate practical backend development skills while delivering a responsive user experience.

🐍 Python

Python is the core programming language used throughout the application. It powers the business logic, data processing, authentication, and communication with the database.

🌐 Flask

Flask provides the web framework responsible for routing, handling requests, rendering templates, managing user sessions, and connecting the frontend with the backend.

🗄 PostgreSQL

PostgreSQL stores application data including users and subscriptions. It provides a reliable relational database with support for complex queries and data integrity.

Database & security

The application uses SQLAlchemy Core for database operations, allowing SQL queries to be written in Python while maintaining clear and maintainable code. User passwords are securely hashed before being stored in the database, helping protect user accounts.

⚙ SQLAlchemy core

SQLAlchemy core manages database connections, table definitions, queries, inserts, updates, and deletes using a powerful SQL expression language.

🎨 HTML & CSS

HTML provides the page structure while CSS creates a clean, modern, and responsive interface designed for both desktop and mobile devices.

📝 Jinja2 templates

Jinja2 connects the Flask backend with the frontend by dynamically rendering pages, passing data, and creating reusable components such as navigation and layouts.

🔐 Authentication

Secure user authentication ensures that each account can safely access its own data through login and registration functionality.

📁 Project structure

The application follows a modular project structure, separating database logic, routes, templates, configuration, and business logic into dedicated modules for easier maintenance.

🚀 Deployment ready

The project is designed with production deployment in mind, using environment variables for configuration and a structure that can be deployed to a Linux server.
