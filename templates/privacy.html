Privacy policy

SubTrack is a portfolio project created to demonstrate backend development, database management, and web application architecture.

This page explains how user information is handled within the application.

Account information

When creating an account, users may provide information such as username and password. This information is stored only for authentication and account management purposes.

Password security

Passwords are not stored as plain text. They are processed using secure password hashing techniques before being saved in the database.

Data usage

User data is used only to provide application features such as account access and subscription tracking. Personal information is not sold or shared.

Project purpose

SubTrack was built as a demonstration project showing how authentication, databases, backend logic, and frontend design can work together in a modern web application.
