About SubTrack

SubTrack is a web application designed to help people organize and manage all of their subscriptions in one simple dashboard. Whether you use streaming platforms, software services, or other memberships, SubTrack keeps everything in one organized place.

My mission

My goal is to make subscription management simple and intuitive. Instead of keeping track of services across multiple apps or notes, everything is available from a single dashboard.

What you can do

Add subscriptions, organize them by category, view all your services in one place, and quickly find the information you need whenever you need it.

Built with

SubTrack is built using Python, Flask, PostgreSQL, SQLAlchemy, HTML, and CSS with a focus on clean code, security, and performance.

Why I built SubTrack

I created SubTrack as a portfolio project to practice backend web development and build a complete application from the ground up. The project combines authentication, database management, responsive design, and a clean user interface into a practical real-world application.

Simple design

Every part of the interface is designed to be clean, modern, and easy to use, allowing users to focus on managing their subscriptions without unnecessary complexity.

Security

User accounts are protected using secure authentication practices, encrypted passwords, and a carefully designed backend architecture.

Purpose

The project demonstrates how modern web technologies can be combined to build a full-stack application that is both practical and maintainable.
